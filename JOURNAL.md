# Investment Journal

*Copy the template below for each entry. Don't edit old entries — your thinking at the
time is valuable data. If you were wrong, that's the most important entry to keep.*

---

## How to use this journal

1. Run the daily briefing (`python main.py`)
2. Read it. Note anything that makes you want to act.
3. Before acting, write a journal entry using the template below.
4. Wait at least 24 hours. Re-read what you wrote. Then decide.

The journal is not about recording trades. It's about recording thinking.
A month of "Action taken: none — observing" is a perfectly valid journal.
